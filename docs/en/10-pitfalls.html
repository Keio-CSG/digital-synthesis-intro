10 Checklist and Common Pitfalls

What to check before signoff, and common failures.

Checklist before signoff

  • RTL simulation PASS (the test is self-checking every time)
  • Synthesis: no warnings in check_design, no setup violations
  • Equivalence checking (after synthesis) PASS
  • Place and route: 0 opens/shorts in check_routes, no hold violations after CTS
  • Extraction has Errors: 0, and every net has parasitics in PrimeTime
  • STA: no violations for setup (slow corner) and hold (fast corner), no warnings in check_timing
  • GLS: PASS with SDF
  • DRC: no geometric rule violations (you can explain every exclusion)
  • LVS: CORRECT (it also confirms that power reaches every cell)

Common pitfalls

SymptomCauseRemedy
Command not foundThe tool environment was not loadedCheck config/local.csh
The library cannot be opened and the tool crashesThe tool version does not match the version that created the libraryOpen the library with the version that created it (use the same version for the extraction tool)
"Cell not found" in a verification tool after netlist outputPhysical-only cells such as fillers are in the netlistExclude them when writing the verification netlist, or provide models
Extraction says "layer not defined"Names in the layer map do not matchCheck the layer names of the layout and write them in the map
GLS outputs are xReset release overlaps the clock edgeRelease reset at a different clock phase
STA slack differs from ICC2Different corner, RC or clock settingsAlign them one by one and compare
Only LVS fails (transistor counts match)Power rails are not connected to the power gridCheck that the vias of the power grid reach every rail (chapter 05, chapter 09)
Warning that ports are unplacedPower ports were not createdIf the signal pins are placed you can ignore it. For a full chip, define the power pins
