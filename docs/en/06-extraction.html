06 Parasitic Extraction

Take the wire resistance and capacitance out of the layout and write them as SPEF.

Background: what is parasitic extraction?

A wire on the chip is not an ideal "just a line". A thin metal wire has resistance (R), and between neighbouring wires and the ground below there is capacitance (C). These slow the signal down and are called parasitic elements.

Parasitic extraction calculates these R and C values from the shapes of the finished layout. The result is a text file called SPEF, used by the signoff STA in the next chapter.

How to run

Easiestmake rcx (from the top of the repository)
Directlycd rcx; csh run_starrc.csh
Inputsicc2/MAC4.ndm (ICC2 layout data), the technology data and layer map for extraction (set in config)
Outputsrcx/MAC4.spef, rcx/starrc.log
Check successgrep -E "ERROR" rcx/starrc.log → nothing printed is OK / ls -l rcx/MAC4.spef
  • make pnr must have been run first.

The tool is Synopsys StarRC. A wire is not "just a line": it has resistance R and capacitance C, and it is coupled to its neighbours by coupling capacitance. We extract these, collect them in a text file called SPEF, and give it to the STA tool.

Inputs

  • The layout (the ICC2 database): which metal belongs to which net.
  • The technology (RC model): extraction data built from the thickness of each layer, the dielectrics and so on.
  • The layer map (config/starrc_layer.map): connects the layer names of the layout to the names in the extraction model. If it is wrong, the run stops with "this layer is not defined".

What to check

  • Errors: 0 in starrc.log.
  • In PrimeTime, report_annotated_parasitics: did almost all nets get parasitics? A wire without parasitics is treated as ideal (zero delay), which makes timing look better than it is.
  • Are resistances present? (A too aggressive REDUCTION setting removes R.)
Corners
In real signoff you extract at a high-capacitance corner (for setup) and a low-capacitance corner (for hold). This course extracts at one corner and switches the corner on the delay-library side.
