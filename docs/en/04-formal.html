04 Equivalence Checking

Prove that the synthesised netlist is logically equivalent to the RTL.

Background: what is equivalence checking?

A logic synthesis tool rewrites and optimises the circuit. If the function changed during this, it is very hard to find in later stages.

Equivalence checking confirms mathematically that the circuit before the rewrite (RTL) and after it (netlist) return the same output for any input. Simulation can only say "it was right for the examples we tried"; this says "it is right in every case".

How to run

Easiestmake fm (from the top of the repository)
Directlycd fm; fm_shell -f fm.tcl >& fm_run.log
Inputsrtl/*.v, dc/MAC4.net.v, dc/MAC4.svf (record of the synthesis optimisations)
Outputsfm/fm_run.log, unmatched.log, failing.log, passing.log
Check successgrep "FORMALITY RESULT" fm/fm_run.log → FORMALITY RESULT: PASS
  • make syn must have been run first.
  • On FAIL, failing.log lists the places that were not equivalent.

Simulation can only show "it is correct for the inputs we tried". Formal equivalence checking shows mathematically that the outputs agree for all inputs.

The tool is Synopsys Formality (fm_shell).

Flow

  1. set_svf: pass the hints of the optimisations done by the synthesis tool (without them, things like state re-ordering often fail).
  2. reference = RTL, implementation = netlist (the cell functions are read from the library).
  3. match: pair up the registers and ports of both (create compare points).
  4. verify: prove, for each compare point, that the combinational logic is equivalent.

If it fails

  • unmatched.log: points that could not be paired. Renamed or constant-propagated registers are typical.
  • failing.log: points that were not equivalent. If something is here, the logic really changed (a synthesis bug, or a difference in how simulation and synthesis interpret the RTL).
When to use it
The standard practice is to run it after synthesis and again after place and route, because the tools touch the logic during physical implementation (buffer insertion, gate swapping and so on).

Exercise

  1. Temporarily change acc + a_q*b_q in the RTL, change only the RTL and run make fm (the netlist stays old). Read the FAIL output.
