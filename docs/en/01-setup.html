01 Setup

Repository layout, and how environment-specific files are kept apart.

Background: repository and command-line basics

A repository is a folder that holds all the files of this course: the circuit (rtl/), the test (tb/) and the run scripts for each tool.

All tools are used from the command line (typing in a terminal). What each tool should do is written in a script, a text file, and the make command calls those scripts in order.

The tools and the libraries (the catalogue of parts) are the ones your lab provides. Their locations are written in config/, which tells the scripts where to look.

Each chapter has a "How to run" box with the inputs, outputs and how to check success for its step.

This repository keeps everything that depends on your environment inside config/. The scripts themselves contain no paths and no library names.

Directory layout

Steps

  1. Get the repository (git clone https://github.com/Keio-CSG/digital-synthesis-intro.git).
  2. Lab members copy the ready-made config. On the lab server it is kept in the folder below (if you cannot open it, ask your supervisor or a senior student). The six files that config/ needs are copied. Existing files are saved as .bak.
  3. Everyone else copies the *.example.* files in config/ and fills in the values for their own environment. These files are listed in .gitignore and are never committed.
  4. Run everything.
Running one step
Name the step: make syn. If the upstream steps have not been run yet, run them first (for example make sta needs make pnr rcx).
