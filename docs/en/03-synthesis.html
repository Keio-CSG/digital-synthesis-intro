03 Logic Synthesis

Set the goal with SDC and convert to gates with DC.

Background: what are logic synthesis and constraints?

RTL says "what to do", but it does not correspond to real parts yet. Logic synthesis converts it into a connection table of basic parts (standard cells) such as AND, OR and flip-flops (1-bit memory). The result is called a netlist.

The same RTL can become different circuits depending on the parts chosen. Faster means larger, smaller means slower (a trade-off). So a person gives "how fast should it be" as constraints (SDC), and the tool looks for the smallest circuit that meets them.

The standard-cell library is a catalogue of the parts' shape, area and delay. The synthesis tool uses the delay values to calculate "will it make it in time?".

How to run

Easiestmake syn (from the top of the repository)
Directlycd dc; dc_shell -f dc.tcl >& dc_run.log
Inputsrtl/*.v, const/MAC4.sdc, the cell timing library (set in config)
Outputsdc/MAC4.net.v (netlist), MAC4.ddc, MAC4.sdc, MAC4.sdf, reports MAC4.*.log
Check successgrep slack dc/MAC4.max.timing.log | head -1 → slack (MET)
  • To try another period, edit CLK_PERIOD in const/MAC4.sdc and run make syn again.
  • To change the corner, set the environment variable CORNER to wc / tc / bc and run directly (for example cd dc; env CORNER=tc dc_shell -f dc.tcl).
  • If it stops midway, look for Error in dc/dc_run.log.

Logic synthesis turns RTL into a connection of gates that meets the constraints. The constraints (SDC) are the specification: the same RTL gives a different circuit under different constraints.

1. Constraints (SDC)

CommandMeaning
create_clockClock period = 2.0 ns (500 MHz). This is the target performance.
set_clock_uncertaintyMargin for skew and jitter. Larger for setup, smaller for hold.
set_input_delay / set_output_delayTime used by the neighbouring blocks. The time left for an input/output path is the period minus the delay.
set_input_transition / set_loadSlope of the input waveform and the load on the outputs.
set_false_path -from rst_nThe asynchronous reset is not timed against the clock.

2. Flow of the synthesis script

  • analyze → elaborate → link: read the RTL, connect the hierarchy and bind it to the cell library.
  • check_design: any unconnected pins or multiple drivers? Always read the warnings.
  • compile_ultra: optimise the logic and map it to cells.
Which corner do we synthesise at?
The rule is: check setup (is it too slow?) at the slow corner and hold at the fast corner. This script switches with CORNER=wc|tc|bc (default: wc). When you quote a number, always state the corner.

3. How to read the reports

  • MAC4.max.timing.log: the tightest setup paths
  • MAC4.min.timing.log: hold paths
  • MAC4.area.log: area.
  • MAC4.qor.log: overall summary.
Timing at this stage is ideal
There is no wire delay and no clock tree yet. Even with margin after synthesis, the slack shrinks after place and route. The signoff in chapter 07 is the final judge.

Exercises

  1. Set CLK_PERIOD to 1.5 and run make syn. Does the slack become negative? How does the area change?
  2. Compare CORNER=tc and CORNER=wc at the same period.
  3. Remove set_false_path. What changes (look at the endpoints in report_timing)?
