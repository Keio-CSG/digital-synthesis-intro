Background: how is a digital chip made?

The CPU in a phone is not drawn transistor by transistor. A designer first describes what the circuit should do in a text-like code (RTL), and tools then convert it step by step into a drawing that a factory can manufacture (the layout).

After each conversion we have to check that the result still matches the original design, is fast enough, and obeys the manufacturing rules. This checking is called signoff. Only when all of it passes can the layout data (GDS) be sent to the factory.

On this site you run the whole flow yourself on one small circuit.

Logic synthesis (RTL → gates) is only the beginning. In this course you take a small circuit through place and route, parasitic extraction, signoff timing, gate-level simulation and physical verification. Every step runs with one command, and you learn how to read its logs.
