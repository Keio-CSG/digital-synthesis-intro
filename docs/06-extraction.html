06 寄生抽出

レイアウトから配線の抵抗・容量を取り出し、SPEF にする。

はじめに: 寄生抽出とは

チップ上の配線は、理想的な「ただの線」ではありません。細い金属には抵抗 (R) があり、隣の配線や下地との間には容量 (C) があります。これらは信号を遅らせる原因で、寄生素子と呼ばれます。

寄生抽出は、完成したレイアウトの形状から、この R と C の値を計算します。結果は SPEF というテキストファイルになり、次の signoff STA で使います。

実行方法

いちばん簡単make rcx（リポジトリの最上位で実行）
直接実行cd rcx; csh run_starrc.csh
入力icc2/MAC4.ndm（ICC2 のレイアウトデータ）、抽出用のテクノロジデータ・層対応表（config で指定）
出力rcx/MAC4.spef、rcx/starrc.log
成功の確認grep -E "ERROR" rcx/starrc.log → 何も出なければ OK ／ ls -l rcx/MAC4.spef
  • 先に make pnr が必要です。

ツールは Synopsys StarRC です。配線は「ただの線」ではなく、抵抗 R と容量 Cを持ち、隣の線とは結合容量でつながっています。これを抽出して SPEF というテキストにまとめ、STA ツールに渡します。

入力

  • レイアウト（ICC2 のデータベース）。どの金属がどのネットか。
  • テクノロジ（RC モデル）: 各層の厚み・誘電体などから作られた抽出用のデータ。
  • 層の対応表（config/starrc_layer.map）: レイアウト側の層の名前と、抽出用モデル側の名前を結ぶ。合っていないと「この層は未定義」というエラーで止まります。

確認ポイント

  • starrc.log の Errors: 0。
  • PrimeTime で読み込んだ時の report_annotated_parasitics: ほぼ全ネットに寄生が付いたか。付いていない配線は「理想（遅延ゼロ）」扱いで、タイミングが甘く出ます。
  • 抵抗が付いているか（REDUCTION の設定が強すぎると R が消えます）。
コーナー
実際のsignoffでは、容量が大きいコーナー（setup 用）と小さいコーナー（hold 用）でそれぞれ抽出します。この教材は1コーナーの抽出で、遅延ライブラリ側のコーナーを切り替えて解析します。
